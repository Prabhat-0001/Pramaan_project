⚠️ The Strict Portal Validation Traps

Legacy NIC/NSP portals reject applications over minor technical rules: Rule 4.2 rejects photos >50KB (smartphone photos are 2MB–5MB), ISO dates (YYYY-MM-DD) cause fatal errors, and multi-tier cascading dropdowns fail on slow connections.

💬 The "Advisory Only" Failure of Modern AI

Chatbots (ChatGPT, Claude) only produce text. They cannot compress a passport photo to 28KB, select dependent tehsil dropdowns, or resolve security CAPTCHAs.

🏛️ The Common Service Centre (CSC) Bottleneck

Rural citizens travel miles, wait in hours-long queues, and face repeated rejections simply to get a physical document typed into a computer.

The Breakthrough Innovation
The PRAMAAN Autonomous Execution Desk
CORE SOLUTION

1. Multimodal Ingestion

  • Reads identity cards and income certificates via Gemini 3.8 Flash Vision.
  • Hands-free voice dictation in English and Hindi.
  • 1-click evaluator test scan generator.
  • Embedded sovereign fallback parser ensures 100% offline uptime.

2. Autonomous Browser Desk

  • Drives a real headless Chromium browser via Playwright.
  • Streams live screenshots and coordinates over Server-Sent Events (SSE).
  • Instant DOM evaluation handles cascading State → District → Tehsil dropdowns in <300ms.

3. Dual Self-Healing Engine

  • Date Format Remediation: Auto-converts rejected ISO dates to DD/MM/YYYY on error.
  • Sharp Image Compression: Shrinks oversized photos from 190KB → 28KB in 24ms when Rule 4.2 triggers.
  • Sanitizes currency and numeric DOM inputs.

🛡️ Ethical Human-in-the-Loop (HITL) Security & Official Receipt

Government portals use CAPTCHAs to prevent bot spam. Instead of crashing, PRAMAAN pauses safely, isolates the canvas pixels (with SVG fallback ensuring zero blank boxes), allows manual or AI vision auto-read, and generates an authentic NIC Application Reference Receipt (NIC/SCHEME/2026/XXXXXX).

Engineering Workflow
End-to-End System Architecture
TECHNICAL ARCHITECTURE
Step 01 • Document Ingestion & Vision OCR: Scans raw certificate image → Gemini 3.8 Flash extracts 11 structured fields → auto-sanitizes currency strings (₹1,80,000 → 180000) & ISO dates.
Step 02 • Quad-Layer Live Scheme Discovery: Queries MyScheme.gov.in API → Web Scraper → Gemini Google Search Grounding for .gov.in domains → Verified Sovereign Registry.
Step 03 • Pre-Flight AI Compliance Audit: Evaluates dossier eligibility and flags portal technical traps (Rule 4.2 and ISO date format) with a strict ≤8s timeout fallback.
Step 04 • Playwright Browser Navigation: Launches Chromium → fills personal details → resolves cascading State → District → Tehsil dropdowns in <300ms without Playwright timeouts.
Step 05 • Dual Self-Healing Trigger: Intercepts #photo-error (>50KB) → Sharp pipeline resizes to 350x450px at 80% quality (-85.1% byte reduction in 24ms) → re-uploads compliant file.
Step 06 • HITL CAPTCHA & Receipt: Pauses for Canvas CAPTCHA challenge → manual or Gemini Vision auto-read → extracts official Application Reference Number & renders printable receipt.
TECH STACK: React 18 • Node.js Express • Playwright • Sharp • Gemini 3.8 Flash
